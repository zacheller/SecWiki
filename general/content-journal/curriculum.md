# Curriculum

[https://www.reddit.com/r/pentest/comments/cwvstm/how\_to\_start\_studying\_to\_get\_into\_cyber\_security/eyiihsv/](https://www.reddit.com/r/pentest/comments/cwvstm/how_to_start_studying_to_get_into_cyber_security/eyiihsv/)

I've received a few messages requesting info for starting out. I'll go ahead and lay out a full curriculum. It will consist of books, online courses \(some free, some not\), and associated certifications.

1. Operating Systems
   1. Windows
      1. ebook: Google for "Windows Operating System Fundamentals" filetype:pdf
      2. ebook: Google for "Windows Server Administration Fundamentals" filetype:pdf
      3. training: [https://www.edx.org/course/windows-server-2016-infrastructure](https://www.edx.org/course/windows-server-2016-infrastructure)
      4. ebook: [https://en.wikibooks.org/wiki/Windows\_Batch\_Scripting](https://en.wikibooks.org/wiki/Windows_Batch_Scripting)
      5. training: [https://www.edx.org/course/windows-powershell-basics-1](https://www.edx.org/course/windows-powershell-basics-1)
   2. Linux
      1. training: [https://www.edx.org/course/introduction-to-linux](https://www.edx.org/course/introduction-to-linux)
      2. training: [https://www.edx.org/course/fundamentals-red-hat-enterprise-linux-red-hat-rh066x](https://www.edx.org/course/fundamentals-red-hat-enterprise-linux-red-hat-rh066x)
      3. ebook: [https://www.tldp.org/LDP/Bash-Beginners-Guide/Bash-Beginners-Guide.pdf](https://www.tldp.org/LDP/Bash-Beginners-Guide/Bash-Beginners-Guide.pdf)
      4. ebook: [https://www.perl.org/books/beginning-perl/](https://www.perl.org/books/beginning-perl/)
   3. Mac \(OS X\)
      1. resource: [https://edu.gcfglobal.org/en/osxbasics/](https://edu.gcfglobal.org/en/osxbasics/)
      2. book: Mac OS X For Unix Geeks, 4th Edition - ISBN: 9780596520625
      3. ebook: [http://macadmins.psu.edu/files/2017/07/psumac2017-212-Practical-Python-for-Mac-Admins-w5hh1r.pdf](http://macadmins.psu.edu/files/2017/07/psumac2017-212-Practical-Python-for-Mac-Admins-w5hh1r.pdf)
   4. OS Other
      1. book: Operating System Concepts 8th Edition - ISBN-13: 978-0470128725
      2. training: [http://www.vmwarevideos.com/free-vmware-training](http://www.vmwarevideos.com/free-vmware-training)
      3. resource: [https://geek-university.com/oracle-virtualbox/oracle-virtualbox-online-course/](https://geek-university.com/oracle-virtualbox/oracle-virtualbox-online-course/)
2. Networking Concepts
   1. training: [https://www.edx.org/course/it-support-networking-essentials-10](https://www.edx.org/course/it-support-networking-essentials-10)
   2. training: [https://www.edx.org/course/digital-networks-essentials](https://www.edx.org/course/digital-networks-essentials)
   3. resource: [https://learningnetwork.cisco.com/thread/15662](https://learningnetwork.cisco.com/thread/15662)
3. Programming
   1. C/C++
      1. resource: [https://www.edx.org/learn/c-plus-plus](https://www.edx.org/learn/c-plus-plus)
      2. training: [https://www.edx.org/course/programming-in-c-getting-started](https://www.edx.org/course/programming-in-c-getting-started)
   2. Python
      1. training: [https://www.codecademy.com/learn/learn-python-3](https://www.codecademy.com/learn/learn-python-3)
      2. book: Python Crash Course, 2nd Edition: A Hands-On, Project-Based Introduction to Programming - ISBN-13: 978-1593279288
   3. Java
      1. resource: [https://introcs.cs.princeton.edu/java/home/](https://introcs.cs.princeton.edu/java/home/)
      2. resource: [https://developer.ibm.com/tutorials/j-introtojava1/](https://developer.ibm.com/tutorials/j-introtojava1/)
   4. Javascript
      1. resource: [https://www.w3schools.com/js/](https://www.w3schools.com/js/)
      2. resource: [https://www.codecademy.com/learn/introduction-to-javascript](https://www.codecademy.com/learn/introduction-to-javascript)
      3. training: [https://www.coursera.org/learn/server-side-nodejs](https://www.coursera.org/learn/server-side-nodejs)
4. Cloud
   1. resource: [https://aws.amazon.com/training/](https://aws.amazon.com/training/)
   2. resource: [https://www.edx.org/learn/azure](https://www.edx.org/learn/azure)
5. Broad Security Concepts
   1. resource: [https://www.edx.org/learn/cybersecurity](https://www.edx.org/learn/cybersecurity)
   2. book: CISSP All-in-One Exam Guide, Eighth Edition - ISBN-13: 978-1260142655
   3. resource: [https://www.owasp.org](https://www.owasp.org/)
   4. resource: [https://nvd.nist.gov/800-53](https://nvd.nist.gov/800-53)
   5. resource: [https://cloudsecurityalliance.org/education/ccsk/study-guide/](https://cloudsecurityalliance.org/education/ccsk/study-guide/)
   6. resource: [https://isc.sans.edu/](https://isc.sans.edu/)

   4. resource: [https://portswigger.net/web-security](https://portswigger.net/web-security)
   5. training: [https://www.offensive-security.com/metasploit-unleashed/](https://www.offensive-security.com/metasploit-unleashed/)
   6. training: [https://www.elearnsecurity.com/course/penetration\_testing/](https://www.elearnsecurity.com/course/penetration_testing/)
   7. training: [https://www.elearnsecurity.com/course/web\_application\_penetration\_testing/](https://www.elearnsecurity.com/course/web_application_penetration_testing/)
