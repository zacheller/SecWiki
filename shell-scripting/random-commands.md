# Random Commands



```text
# lsattr - list existing file attributes
$ lsattr /bin/nsh
----i---------e---- /bin/nsh

chattr - change attribute
$ sudo chattr -i /bin/nsh

$ lsattr /bin/nsh
--------------e---- /bin/nsh



# shows all running processes and the command lines used to startup the processes 
ps -eafw
```
